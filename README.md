# ampladder

Checks for intracranial decoding benchmarks, and the code and results behind a study of the
Neuroprobe benchmark of stereo-EEG decoding.

Per-window normalization removes the absolute amplitude of a signal, and decoders on a shared
benchmark differ in whether they apply it. The study measures how much of what decoders read on
Neuroprobe Lite is amplitude, with an *amplitude ladder*: feature sets decoded with the benchmark's
own windows, splits and classifier that differ only in whether amplitude survives. It also measures
three properties of the benchmark's construction from its code: time leaking through the
within-session folds, an early-stopped reference classifier, and electrode selection on the
evaluated sessions' own test performance.

## The package

```
pip install "git+https://github.com/SamirHossain099/ampladder"
```

* `ampladder.ladder`: amplitude-only (log variance), amplitude-free (generalized Hurst exponents
  h(q), q = 1, 2, 3, 5) and spectral-shape feature sets.
* `ampladder.foldaudit`: how far a benchmark's folds let the time of a window predict its label,
  from the index alone (no neural data), and folds rebuilt on a time boundary shared by both classes.
* `ampladder.selection`: Neuroprobe's electrode-selection rule, ported verbatim, for comparing
  circular selection (scored on the evaluated session) with cross-fitted selection.
* `ampladder.mfdfa`: batched DFA and MFDFA, validated against
  [fdnkit](https://pypi.org/project/fdnkit/) to 1e-9, with an optional GPU backend.

`tests/test_matches_paper.py` requires the package to compute exactly what the analysis scripts
computed for the paper.

## The study

* `analysis/`: every script that produced a number in the paper. Feature extraction and decoding
  need the Brain Treebank recordings (https://BrainTreebank.dev/, CC BY 4.0, about 76 GB) and
  Neuroprobe (https://github.com/insight-neuro/neuroprobe, MIT, commit b901984). `download_braintreebank.py`
  records a SHA-256 for every file; `results/provenance/` holds the hashes of the copy analysed.
  Paths default to the author's data drive and can be set on the command line.
* `results/`: the tables the scripts wrote: per-cell AUROC for every feature set and split, the
  hypothesis tests, and the follow-up and sensitivity analyses. Large intermediate files (features,
  the window index) are not included and are regenerated by the scripts.
* `figures/`: the figures, each with the numbers it plots as JSON.

Docstrings refer to the study's working notes and pre-registration by section; these are not part
of this repository. The analyses they describe are reported in the paper.
